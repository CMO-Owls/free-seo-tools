# cmoowls-seo-tools

Free SEO and AI-visibility checks from [CMO Owls](https://www.cmoowls.com/): robots.txt and AI crawler access, llms.txt,
sitemaps, indexability, redirects, structured data, broken links, meta tags, Open Graph, images, mobile and security headers.
The same engine runs the free tools at [cmoowls.com/tools](https://www.cmoowls.com/tools/).

```bash
pip install "git+https://github.com/CMO-Owls/free-seo-tools.git#subdirectory=python"
cmoowls-seo --help
cmoowls-seo indexability https://example.com/
```

Full documentation, real examples and the list of all 23 tools: [github.com/CMO-Owls/free-seo-tools](https://github.com/CMO-Owls/free-seo-tools).
